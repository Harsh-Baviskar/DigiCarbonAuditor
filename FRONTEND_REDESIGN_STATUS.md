## 🎨 Key Design Features

### Color System (Professional Climate-Tech)
- **Primary**: #437057 (Forest Green) - Trustworthy, visible
- **Secondary**: #5C8374 (Sage) - Calming, supporting
- **Accent**: #97B067 (Lime Sage) - Growth, positive
- **Deep**: #4a6b33 (Dark Teal) - Authority, emphasis
- **Highlight**: #E3DE61 (Soft Yellow) - Important items
- **Surfaces**: Light sage tints - Professional backgrounds

### Typography Scale
- **H1**: 2.5rem (40px) - Page titles
- **H2**: 2rem (32px) - Section titles
- **H3**: 1.5rem (24px) - Subsections
- **Body**: 1rem (16px) - Standard text
- **Small**: 0.875rem (14px) - Secondary text
- **Font weights**: 400, 500, 600, 700 (clear hierarchy)

### Spacing System (8px Grid)
- **XS**: 4px | **SM**: 8px | **MD**: 16px
- **LG**: 24px | **XL**: 32px | **2XL**: 48px

### Shadow Effects (3-Tier)
- **Small**: 0 1px 2px rgba(0,0,0,0.05)
- **Medium**: 0 2px 8px rgba(0,0,0,0.08) [default]
- **Large**: 0 4px 16px rgba(0,0,0,0.12) [hover]
